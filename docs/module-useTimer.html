Module: useTimer

Custom hook that provides timer functionality for tracking game duration. Manages an interval to count seconds and provides controls to start, stop, and reset.

Parameters:
Name Type Attributes Default Description
initialActive boolean <optional>
 false

Determines if the timer should start immediately upon initialization.
Properties:
Name Type Description
seconds number

The total elapsed time in seconds.
formatTime function

Returns the elapsed time formatted as a string (MM:SS).
start function

Starts or resumes the timer interval.
stop function

Pauses the timer interval.
reset function

Resets the elapsed seconds back to zero.
isActive boolean

Current state indicating whether the timer is currently running.
