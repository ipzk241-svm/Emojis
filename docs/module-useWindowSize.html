Module: useWindowSize

Custom hook to track the current dimensions of the browser window. Listens to the 'resize' event and updates the state accordingly. Useful for responsive calculations, such as determining the number of columns in the game board.

Properties:
Name Type Description
width number | undefined

The current inner width of the window in pixels.

The current inner height of the window in pixels.
