Memory Game (React Project)

A memory training game where you need to find matching emoji pairs. Created as part of the "Компонентно орієнтоване програмування" course.

👤 Author

Serhiiko Vasyl

🛠 Configuration and Setup

  1. Install dependencies: npm install
  2. Run in development mode: npm start
  3. Run Storybook: npm run storybook
  4. Build the project: npm run build
